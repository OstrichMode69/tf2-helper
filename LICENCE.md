## 🧩 About

**Team Fortress 2 Helper** is a comprehensive mod menu for Team Fortress 2 featuring overlay menu, class loadout manager, HUD customization, config scripts, and server browser.

Based on popular mods like **OpenHack**, **Eclipse Menu**, and **QOLMod**.

## ✨ Features

### 🎮 Core Hacks
- Overlay Menu — in-game overlay with quick access to all features
- Speedhack — adjust game speed (0.1x to 5x)
- Aim Assist — assist aiming with configurable settings
- Wallhack — see enemies through walls
- No Recoil — eliminate weapon recoil

### 🎨 Cosmetics & Unlocks
- Unlock All Cosmetics — access all hats, miscs, and taunts
- Custom Skin Unlock — apply any weapon skin
- Killstreak Effects — enable special killstreak effects
